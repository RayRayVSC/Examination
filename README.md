# 8字水平圓 飛行示範動畫

民航局 AC-107 遙控無人機操作證術科測驗「無人多旋翼機 基本級」項目 **C. 8字水平圓** 的 Three.js 3D 飛行示範。

線上觀看：https://rayrayvsc.github.io/drone-figure8-animation/

## 飛行流程（依 AC-107 測驗準則 p.163）

1. 口誦「3、2、1、Go」
2. 機頭朝外，自起降點 H 起飛至約 1.5 m，定點懸停 5 秒
3. 前進至 P4，逆時針繞行 P4 → P1 → P2 → P3 → P4（左圓）
4. 順時針繞行 P4 → P5 → P6 → P7 → P4（右圓），全程機頭朝飛行方向、等高等速
5. 後退返航 H，機頭朝外等高懸停，口誦「結束」

## 操作

- 空白鍵 播放/暫停、R 重來、C 切換視角（環繞 / 站位 / 俯視 / 跟隨 / FPV）
- ← → 前後 2 秒、拖曳時間軸、速度 0.5x–4x
- 環繞視角可用滑鼠拖曳旋轉、滾輪縮放；「儲存自訂視角」可記住調好的角度

考場尺寸：角錐圓 6 m、內圓 4 m、外圓 8 m。場地佈置沿用 [Drone-Simulator](https://github.com/tamago797/Drone-Simulator-)。
