# 無人多旋翼機基本級術科動畫

民航局 AC-107 遙控無人機操作證術科測驗「無人多旋翼機 基本級」五個飛行科目的 Three.js 3D 示範動畫，單一網頁切換科目。

線上觀看：https://rayrayvsc.github.io/Examination/

| 科目 | 內容 |
| --- | --- |
| B. 定點起降及四面停懸 | 起飛、四次順時針旋轉 90° 懸停、降落，附旋轉與起降箭頭 |
| C. 8字水平圓 | 逆時針左圓、順時針右圓、後退返航 |
| D. 側面懸停及前進、後退 | 機頭朝左／朝右各三段前進後退，附 ①～⑥ 箭頭 |
| E. 高度保持五邊飛行 | 沿 80 × 20 m 空域邊緣五邊飛行，爬升至指定高度 |
| F. 緊急處置程序 | 五邊飛行途中下達緊急返航，進場降落於較近一側內圈 |

## 操作

- 左下按鈕切換科目；預設 B，播完 1 秒後自動接續下一科目（循環播放關閉時）。
- 空白鍵 播放/暫停、R 重來、C 切換視角、← → 前後 2 秒、I/O 焦距、↑↓ 站位視角高度。
- 六種視角：環繞、站位、俯視（正交）、追蹤、跟隨、FPV；「自訂視角儲存」可依視角記住設定。
- 人偶（簡易／義勇 3D 模型）與無人機（T110／簡易）可切換。
- E、F 可切換頂風方向；F 可隨時按「下達緊急返航」。

## 網址參數

`?subject=b|c|d|e|f`、`t=秒數`、`cam=視角編號`、`avatar=giyu`、`drone=simple|t110`、`dir=right`、`emg=秒數`。
例：`Examination.html?subject=f&t=30`

場地佈置沿用 [Drone-Simulator](https://github.com/tamago797/Drone-Simulator-)（角錐圓 6 m、內圓 4 m、外圓 8 m、場地 30 × 23 m、空域 80 × 20 m）。
